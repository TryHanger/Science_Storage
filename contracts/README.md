# Синтетические контракты — не реальные статьи

- `schema.sql` — начальная SQL-схема (шесть таблиц).
- `EXAMPLE_JOB_SYNTHETIC.zip` — демонстрация формата задания на 50 **вымышленных** записей.
- `example_results.json` — фиктивный ответ для проверки валидатора и сохранения 50 решений.
- `response_schema.json` — JSON Schema ответа GPT; отдельно всегда проверять точное множество `work_id` по manifest.
- `gold_set_template.csv` — пустой шаблон для независимой экспертной разметки.

Синтетические данные не использовать для научного screening и не выдавать за реальный OpenAlex-импорт или ответ GPT.
